## hello_ai_office

### Instructions:
1. Clone the repository:
   git clone https://github.com/your-username/hello_ai_office
2. Navigate to the project directory:
   cd hello_ai_office
3. Install dependencies:
   pip install -r requirements.txt
4. Run the application:
   python main.py

### Notes:
- The application is designed to run with the following dependencies:
  - Python 3.10+
  - pip
- The application is currently in development and may have some issues with the backend.

### Development Environment:
- Python 3.10
- pip
- Virtual Environment
